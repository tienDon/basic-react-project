# Basic React Project

This is a React project built with Vite. It includes mini projects such as a Counter and Todo List.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/tienDon/basic-react-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd basic-react-project
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

- Navigate to the homepage to see the list of mini projects.
- Click on a project title to view its functionality.

## Technologies

- React
- Vite
- Tailwind CSS
- React Router
